# IX-ON

**Innovate Tomorrow, Today** — Engineering the Future Through Intelligence, Collaboration & Execution.

A modern, high-performance React application rewritten with Vite, TypeScript, and Tailwind CSS, preserving the original brand aesthetics, interactive sections, and design fidelity.

## Features

- **Responsive Navigation**: Fixed glassmorphism header with smooth-scrolling navigation and mobile drawer.
- **Hero Section**: Radial animated glow background with primary call-to-action.
- **Tech Hub**: Strategic consulting and enterprise-grade architecture presentation.
- **Tech Lounge**: Innovation community and collaborative lab showcase.
- **Tech Solution**: High-performance execution engine across software, data, and security.
- **Execution Framework**: Interactive 4-stage delivery timeline (Discover, Architect, Build, Scale).
- **Why IX-ON**: Enterprise value proposition grid with reactive glass cards.
- **Contact & Inquiry**: Quick copy-to-clipboard, mailto link, and interactive project inquiry form.

## Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide React**

## Development

```bash
npm run dev
```

The app will be available on port 3000 (`http://localhost:3000`).

## Build

```bash
npm run build
```
